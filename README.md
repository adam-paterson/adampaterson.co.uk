# adampaterson.co.uk

Personal website and blog built with [Astro](https://astro.build), TypeScript, and Tailwind CSS.

## Overview

This is the source for my personal site — a fast, content-focused portfolio and blog where I write about AI/ML architecture, commerce intelligence, and responsible AI practices.

## Tech Stack

- **Framework**: [Astro](https://astro.build) — static site generation with islands architecture
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Cloudflare Pages

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Structure

- `src/pages/` — Routes and content pages
- `src/components/` — Astro/React components
- `src/layouts/` — Page layouts
- `public/` — Static assets
